A LITTLE FIELD GUIDE

Start building your corpus

  1. Optionally enter an annotator ID, then paste a video link.

    Each new clip records this annotator in the exported JSON; it does not create an account. Clip ranges, notes, and tags are your annotations.

  2. Play, mark, and record your observations.

    Click “Use current” or enter seconds or mm:ss.sss. Click Add clip to place it in the list below. Each video has its own clips and unfinished draft; switch videos in the library.

  3. Export JSON to share with your project lead.

    Exports save a JSON file through the local server. The dialog shows its location. Import the file to continue annotating.

SpacePlay / pauseIMark startOMark end⌘ / Ctrl ↵Add clip

Shortcuts work outside text fields. If the YouTube player has focus, click elsewhere on this page first. The save shortcut also works inside clip fields.

Local storage: Annotations and unfinished drafts are saved in this browser’s localStorage. Storage is separate for each browser, host, and port; clearing browser data removes it. Export regularly, and avoid editing the same project in multiple tabs.

YouTube limitations: Videos need internet access and must allow embedding. The page has no comments or recommendation sidebar, but YouTube controls the player’s branding, ads, and end recommendations. You can still enter times manually if playback fails. Times are stored to milliseconds, without a guarantee of frame accuracy.

Audio and subtitles: Use Download video for the full video, a clip row for one clip, or Download all for all clips of the selected video. Choose a save folder before starting. Video downloads include source audio. Audio-only extraction and subtitle import are not implemented yet.
